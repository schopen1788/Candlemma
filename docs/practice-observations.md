# 연습 근거 세분화

연습의 근거 선택을 **관찰 → 방향 판단 → 관찰/방향 피드백** 흐름으로 변경했다.

- 9개 분류, 총 44개 항목: 추세 4, 지지선 4, 저항선 4, 박스권 4, 이동평균선 7, 캔들 6, 갭 5, 거래대금 6, 공시·뉴스 4.
- 분류를 선택하면 해당 항목과 확인 기준을 펼친다. 전체 분류를 통틀어 1~3개 선택하며, 선택한 항목은 위에서 언제든 해제할 수 있다.
- 공시·뉴스가 제공되지 않은 문제에서는 해당 분류에 안내를 표시하고 항목 선택을 제공하지 않는다. 숨겨진 공시나 미래 정보로 관찰 여부를 확인하지 않는다.
- 결과의 ‘내 관찰 확인’은 선택별 일치 여부, 실제 적용한 수치 기준, 추가 관찰 예시를 제공한다. 이후 방향 정답과 관찰 일치 여부는 별개다.
- 방향 정답 100점, 선택한 관찰 중 하나 이상 일치하면 20점이다. 관찰 기준은 게임의 명시적 수치 기준이며 유일한 차트 해석을 뜻하지 않는다.
- 복기 노트에는 내부 ID 대신 읽을 수 있는 관찰 이름을 저장한다. 과거 노트도 계속 표시한다.

## 기존 데이터·랭킹과의 호환성

`POST /api/puzzles/open`의 `observation_version: 2` 요청만 새 관찰 모드를 연다. 새 클라이언트가 이 값을 보내며, 서버의 `opens.context`에는 `practice:observations-v2`로 기록한다.

이전 클라이언트 또는 이전에 발급한 연습 토큰은 기존 12개 태그와 채점 기준을 유지한다. 서버에서 토큰의 context를 확인하므로 제출 시점의 클라이언트 값으로 기준을 바꿀 수 없다.

랭킹도 새 클라이언트의 `POST /api/game/start` 요청에 `observation_version: 2`를 보내 동일한 9개 분류와 관찰 피드백을 사용한다. 시즌은 `all-observations-v2`, 규칙은 `direction100-observations20-v2`다. 시작할 때 공개 차트로 계산한 관찰 ID를 `game_questions.key_tags`에 고정하고 서버가 이를 채점한다. 제출 전에는 일치 여부를 내려주지 않는다. 공시가 없는 문제의 공시 근거 등 선택 불가능한 ID도 거절한다.

기존 `all-v1` 기록은 보존하며 랭킹 화면의 ‘이전 근거 랭킹’에서 조회한다. `GET /api/ranking`과 `/api/ranking/me`는 새 기준을 기본으로 사용하며 `?season=all-v1`로 이전 기록을 조회할 수 있다. 기존 클라이언트의 버전 없는 시작 요청과 진행 중인 기존 게임은 이전 채점 방식을 유지한다. 등록 시 게임이 속한 시즌의 내 순위를 반환하고, 서로 다른 시즌의 점수를 섞지 않는다.

새 화면은 별도 복원 키 `cm.rankedGame.observations-v2`를 사용해 이전 게임 때문에 예전 근거 화면이 계속 보이지 않게 한다. 랭킹 도전 진입 시 5·20·60일선을 모두 켜고 게임 중에는 자유롭게 끌 수 있다. 연습의 저장된 선택과는 독립적으로 초기화한다.

원본 문제 페이로드를 변경하지 않는다. 연습은 기존 D1 테이블의 context/tags 필드를 사용하며, 랭킹은 `0003_ranked_observations.sql` 마이그레이션으로 새 시즌 행만 추가한다. 데이터 재수집·정답 데이터 재적재는 필요 없다. 선택 비율 집계는 구·신 버전을 모두 포함하며 랭킹 답안은 등록한 게임만 집계한다.

## 판정 구현

항목과 설명은 `config/reasons.yaml`, 생성은 `scripts/build-config.mjs`, 판정은 `apps/api/src/observations.ts`에서 관리한다. ID는 기록에 저장되므로 이름을 수정하더라도 유지한다. 기준을 바꿀 경우 설명·판정 함수·테스트를 함께 변경한다.

판정 함수는 공개 차트만 입력받으며 정답·미래 캔들을 인자로 받지 않는다. `d <= 0`의 캔들과 화면에 표시하는 첫 5개 공개 정보만 검사한다. 이동평균선은 표시된 값을 우선 사용하고, 없으면 보이는 종가로 계산한다. 거래대금 비교의 평균에는 당일을 포함하지 않는다. 비교 기간이 부족한 항목, 거래대금 평균 0, 고저 폭 0 등은 판정을 생략한다.

선택 가능한 차트 항목은 실제로 어떤 항목이 일치하는지에 따라 숨기거나 강조하지 않는다. 정답은 제출 이후에만 피드백한다.
